# Abstract

**Efficiency Frontiers of Parameter-Efficient Fine-Tuning Under Compute and Memory Constraints**

Parameter-efficient fine-tuning (PEFT) is now standard practice for adapting large language models, but the design space — adapter family, rank, and base-model precision — is rarely characterized along *hardware* axes under a matched compute budget. We present a controlled empirical study that fixes a single backbone (Qwen2.5-1.5B), three downstream tasks spanning binary classification (SST-2), multiple-choice commonsense reasoning (HellaSwag), and chain-of-thought math (GSM8K), and a fixed optimizer-step budget per task, and varies one axis at a time across **117 runs** (3 seeds each) on a single RTX 6000 Ada GPU. We report two efficiency metrics throughout — accuracy per trainable parameter and accuracy per GPU-hour — alongside peak VRAM and throughput. Three findings push back on common intuitions. (i) **LoRA rank scales inversely with task difficulty under a fixed step budget**: on GSM8K, accuracy *decreases monotonically* from r=4 to r=64 (55.2 → 48.3 %), while HellaSwag improves monotonically and SST-2 saturates by r=4 — suggesting optimization, not adapter capacity, is the binding constraint for reasoning. (ii) **QLoRA's accuracy tax is task-dependent**: INT4 quantization cuts peak VRAM by 44–48 % with no measurable loss on classification, but loses 5.7 pp on GSM8K, where compounding numerical error in attention scores degrades chain-of-thought generation. (iii) **IA³ dominates the statistical-efficiency frontier**: with 0.27 M trainable parameters (8× fewer than LoRA r=16, 5 800× fewer than full fine-tuning), it matches LoRA on classification and even exceeds full fine-tuning on HellaSwag, while prefix-tuning at this model scale fails to learn. The overall Pareto picture argues for IA³ as the default for classification, low-rank BF16 LoRA for reasoning, and QLoRA only when memory is genuinely binding. All experiments share one YAML-configured harness so accuracy/parameter and accuracy/GPU-hour are computed identically across cells; code and per-run artifacts are released for full reproducibility.
