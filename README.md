# 6787-lora

**CS 6787 Final Project (Spring 2026) — *Efficiency Frontiers of PEFT Under Compute and Memory Constraints***

A single experimental harness that fine-tunes **Qwen2.5-1.5B** on three tasks (SST-2, HellaSwag, GSM8K) across a matrix of PEFT methods (full / LoRA / IA³ / prefix) and precisions (FP32 / BF16 / INT4 QLoRA), then rolls accuracy + hardware metrics into one CSV. Every cell of every experiment is one YAML config consumed by the same `python -m src.train --config <yaml>` entry point — that's what makes accuracy / param and accuracy / GPU-hour comparable across runs.

## Experiments

| Phase | What | Status |
|---|---|---|
| Exp 1 | LoRA rank sweep (r ∈ {4,8,16,32,64}) + full-FT baseline | complete (54 / 54) |
| Exp 2 | Precision sweep at fixed LoRA r=16 (FP32 / BF16 / INT4 QLoRA) | complete (27 / 27) |
| Exp 3 | PEFT method comparison (LoRA r=16 / IA³ / prefix-20 / full) | complete (36 / 36) |

All runs are pinned to a single **NVIDIA RTX 6000 Ada (48 GB)** node (the proposal's Blackwell node was unavailable). See [`docs/REPORT.md`](docs/REPORT.md) for the running write-up and [`docs/internal/PROGRESS.md`](docs/internal/PROGRESS.md) for the phase-by-phase status log.

## Quickstart

All runs go through the project venv from the repo root; relative paths (`results/`, `configs/`) are baked into `src/results.py`.

```bash
PY=./.venv/bin/python

# Generate the YAML config matrix for an experiment.
$PY scripts/generate_configs.py --experiment exp1   # or exp2 / exp3 / all

# Run a single config (idempotent — short-circuits if metrics.json exists; --force to override).
$PY -m src.train --config configs/exp1/sst2/exp1__lora_r16__sst2__seed0.yaml

# End-to-end smoke test (~5 min, asserts SST-2 acc > 0.65 after 50 steps).
$PY scripts/smoke_test.py

# Roll results/runs.csv into per-experiment summary tables + matplotlib figures.
$PY scripts/analyze.py --experiment all

# SLURM array dispatch (pinned to nvidia_rtx_6000_ada_generation).
sbatch jobs/exp1_lora_rank.sh
sbatch jobs/exp2_precision.sh
sbatch jobs/exp3_peft.sh
```

## Repository structure

```
6787-lora/
├── CLAUDE.md                    # Architectural notes / invariants for the harness
├── requirements.txt             # Pinned deps (transformers, peft, bitsandbytes, ...)
├── preliminary_exploration.py   # One-off pre-project scratch (kept for reference)
│
├── src/                         # The harness — same code path for every run
│   ├── train.py                 #   Single-run entry point: load → train → eval → write
│   ├── config.py                #   RunConfig schema + YAML loader
│   ├── model.py                 #   build_model: dispatch over (precision, peft_method)
│   ├── instrumentation.py       #   TrainTimer (wall + peak VRAM)
│   ├── results.py               #   Per-run artifacts + append to results/runs.csv
│   ├── seeding.py
│   ├── data/                    #   Per-task dataset + prompt formatting
│   │   ├── registry.py          #     task name → module
│   │   ├── _format.py           #     tokenize_with_completion (label-masked)
│   │   ├── sst2.py / hellaswag.py / gsm8k.py
│   └── eval/
│       ├── loglikelihood.py     #     MC scoring (SST-2, HellaSwag)
│       └── gsm8k_gen.py         #     Greedy-decode + #### N regex extract
│
├── configs/                     # Generated YAML matrix; one file per (exp, task, variant, seed)
│   ├── exp1/{sst2,hellaswag,gsm8k}/
│   ├── exp2/...
│   └── exp3/...
│
├── scripts/
│   ├── generate_configs.py      # Writes the YAML matrix under configs/<exp>/<task>/
│   ├── smoke_test.py            # Canonical "did I break the harness" check
│   └── analyze.py               # runs.csv → summary.csv + figs/*.png
│
├── jobs/                        # SLURM submission scripts
│   ├── exp{1,2,3}_*.sh          #   Array dispatch per experiment
│   ├── run_one.sh               #   Single-config slurm wrapper
│   └── smoke.sh
│
├── results/                     # Generated outputs (append-only)
│   ├── runs.csv                 #   Master log; source of truth for analyze.py
│   ├── runs/<run_id>/           #   Per-run config.yaml + metrics.json + train_log.jsonl
│   └── exp{1,2,3}/
│       ├── runs/<run_id>/       #     Same artifacts, partitioned per experiment
│       ├── summary.csv          #     Generated by analyze.py
│       └── figs/*.png           #     Generated by analyze.py
│
├── slurm/                       # Captured stdout/stderr from SLURM array runs
│
├── docs/
│   ├── REPORT.md                # Running project report (intro, methods, per-exp results)
│   └── internal/PROGRESS.md     # Phase-by-phase status log
│
└── proposal/
    ├── CS6787_Proposal.pdf
    └── project_proposal.txt
```
